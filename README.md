# Retail KPI - Data Quality Project

## 📊 Overview
Built a complete Data Quality framework for Retail Education dataset. Cleaned 5000+ rows of messy sales data and defined 8 business KPIs.

## 🔧 What I Did
- Data Cleaning using Python (Pandas) - handled nulls, duplicates, invalid values
- Created KPI Dictionary with formulas, ownership & grain
- Executed profiling checks: completeness, uniqueness, validity, consistency, freshness
- Before/After cleaning comparison with proof

## 💻 Tech Stack
Python, Pandas, Jupyter Notebook, Data Quality Concepts

## 📁 Files
- `Task03_Cleaning.ipynb` - Main cleaning code
- `retail-orders-clean.csv` - Cleaned dataset
- `cleaning_before_after.png` - Results proof

## 📈 KPIs Defined: 8
Sales, Profit, Return Rate, etc with full contract
